# FashionHub

FashionHub is a simple, responsive landing page for a fashion storefront.

## Live site

[Visit FashionHub](https://fashionhub-cm0.pages.dev/)

## Getting started

Open `index.html` in a web browser. The page is static and does not require a build step or dependencies.

## Project files

- `index.html` — the FashionHub storefront entry page.
- `lookbook/index.html` — a fashion lookbook with outfit inspiration.
